## 🔎 What This Document Covers

This document describes how Universum Infinitum: Flags at https://github.com/hmlendea/stellaris-ui-flags handles personal data. It covers the application behaviour and verified integrations described below. Where the software is self-hosted, the instance operator may have separate responsibilities described below.

This document covers the mod's local game assets and does not cover Stellaris, distribution platforms, or other software operated by third parties.

## 📥 Data We Handle

### Data Provided to the Application

- The mod does not request personal data from players.

### Data Generated or Collected by the Application

- The mod does not automatically generate or collect personal data, telemetry, diagnostics, or usage data.

### Data Received from Integrations

- The mod has no integrations and receives no personal data from third parties.

## 🧭 Processing and Use

The application processes the data described above for these verified functions:
- The mod supplies flag and background assets to Stellaris — no personal data is involved.

## 🗄️ Storage, Retention, and Deletion

The mod is a set of game assets installed locally or made available through a distribution platform. It does not store personal data, so the project has no personal-data retention period or deletion mechanism. Storage, retention, and deletion of data handled by Stellaris or a distribution platform are outside this project's scope.

## 🔗 External Processing and Integrations

The mod has no built-in external data transfer or integrations. Users may obtain it through GitHub, Steam Workshop, Paradox Mods, or Nexus Mods, as linked in the [README](README.md). Any data those platforms process when users access their services is handled independently under the platforms' own policies and is not sent to or received by the mod.

## 🛡️ Data Protection and Security

The mod does not handle personal data and is distributed as game assets rather than an account-based or network service. The project does not operate a service that stores player data. Keep Stellaris and the mod updated, and use the distribution platform's own settings for platform data. No system can be guaranteed completely secure.

## 🔄 Document Changes

Update this document when application data flows, storage, integrations, or deployment responsibilities change. The current version is published at [PRIVACY.md](PRIVACY.md).

## 📬 Contact

For data-handling questions, use the project's [GitHub issue tracker](https://github.com/hmlendea/stellaris-ui-flags/issues).

For questions about application data handling, contact the project maintainers. For a self-hosted instance, contact the instance operator, unless the project explicitly handles the request. Include the mod version or relevant distribution channel; do not send passwords, access tokens, or other secrets.
