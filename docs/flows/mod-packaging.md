# Mod Packaging Flow

## Overview

This document describes the mod packaging process — how the build pipeline assembles the final Stellaris-compatible mod package from converted assets and static files.

## Descriptor Files

### Root Descriptor (`out/ui-flags.mod`)

**Location:** `out/` (parent of mod package)

**Purpose:** Read by Stellaris launcher when mod is installed in `Documents/Paradox Interactive/Stellaris/mod/`

**Content:**
```ini
name="Universum Infinitum: Flags"
path="mod/ui-flags"
supported_version="v4.5.*"
tags={
    "Graphics"
}
picture="thumbnail.png"
```

**Field Details:**

| Field | Value | Source | Notes |
|-------|-------|--------|-------|
| `name` | `MOD_NAME` | `build.sh` constant | Display name in launcher |
| `path` | `mod/ui-flags` | Hardcoded | Relative to mod root directory |
| `supported_version` | `STELLARIS_VERSION` | `build.sh` constant | Game version compatibility |
| `tags` | `{"Graphics"}` | Hardcoded | Mod category filter |
| `picture` | `thumbnail.png` | Hardcoded | Mod icon in launcher |

**Path Resolution:** When placed in `Documents/Paradox Interactive/Stellaris/mod/ui-flags.mod`, the game looks for mod content at `Documents/Paradox Interactive/Stellaris/mod/ui-flags/`.

### Package Descriptor (`out/ui-flags/descriptor.mod`)

**Location:** Inside mod package (`out/ui-flags/`)

**Purpose:** Read when mod is loaded from `mod/ui-flags/` directory directly

**Content:**
```ini
name="Universum Infinitum: Flags"
path="."
supported_version="v4.5.*"
tags={
    "Graphics"
}
picture="thumbnail.png"
```

**Key Difference:** `path="."` (current directory) vs `path="mod/ui-flags"`

**Use Case:** When user copies entire `ui-flags/` folder to mod directory.

## Static Asset Staging

### Background Textures

**Source:** `source/backgrounds/*.dds`

**Destination:** `out/ui-flags/flags/backgrounds/`

**Operation:** `cp -r source/backgrounds/* out/ui-flags/flags/backgrounds/`

**Count:** 40+ files

**Format:** DDS (copied verbatim — no conversion)

**Stellaris Usage:** Available as flag background options in empire customisation.

### Colour Palette

**Source:** `source/colours.txt`

**Destination:** `out/ui-flags/flags/colors.txt` (note: `colors.txt` US spelling)

**Operation:** `cp source/colours.txt out/ui-flags/flags/colors.txt`

**Format:** Stellaris colour definition format

**Stellaris Usage:** Defines available colours for flag/map/ship contexts.

### Localisation

**Source:** `source/localisation.yml`

**Destination:** `out/ui-flags/localisation/ui-flags_l_english.yml`

**Operation:** `cp source/localisation.yml out/ui-flags/localisation/ui-flags_l_english.yml`

**Rename:** File renamed to include mod prefix (`ui-flags_`)

**Format:** YAML with `l_english:` prefix

**Stellaris Usage:** Category display names in empire customisation.

### Thumbnail

**Source:** `source/thumbnail.png`

**Destination:** `out/ui-flags/thumbnail.png`

**Operation:** `cp source/thumbnail.png out/ui-flags/thumbnail.png`

**Specifications:** PNG, recommended 256×256px

**Stellaris Usage:** Mod icon in launcher, Steam Workshop, Nexus Mods.

### Usage Files

**Source:** `source/flags/<category>/usage.txt` (optional)

**Destination:** `out/ui-flags/flags/<category>/usage.txt`

**Operation:** Copied during category iteration if exists

**Purpose:** Documentation for category-specific usage restrictions.

## Flag Asset Organisation

### Directory Structure Per Category

```
out/ui-flags/flags/<category>/
├── map/
│   └── <flag_name>.dds          # 256px, flat
├── small/
│   └── <flag_name>.dds          # 24px, beveled
└── <flag_name>.dds              # 128px, beveled
```

### Naming Resolution

**Function:** `get-flag-file-name(names.txt, source_filename)`

**Logic:**
1. Look up `source_filename` (without extension) in `names.txt`
2. If found: use mapped value
3. If not found: use `ui_` + `source_filename`

**Example:**
| Source File | names.txt Entry | Output Name |
|-------------|-----------------|-------------|
| `eagle.svg` | `eagle=ui_domination_1` | `ui_domination_1.dds` |
| `logo.png` | (none) | `ui_logo.dds` |

### Three Variants Per Flag

| Variant | Resolution | Bevel | Directory | Purpose |
|---------|------------|-------|-----------|---------|
| Main | 128×128 | Yes | `flags/<cat>/` | Empire flag, diplomacy |
| Map | 256×256 | No | `flags/<cat>/map/` | Galaxy map |
| Small | 24×24 | Yes | `flags/<cat>/small/` | UI icons, fleets |

## Package Validation

### Implicit Validation (Build Success)

The build completes successfully only if:
- All tool validations pass
- All directory creations succeed
- All file copies succeed
- All descriptor generations succeed
- At least one asset processes without fatal error

### Explicit Validation (Pre-Release Checklist)

Run after build, before distribution:

```bash
# 1. Check descriptor files
cat out/ui-flags.mod
cat out/ui-flags/descriptor.mod

# 2. Verify structure
find out/ui-flags -type f | sort

# 3. Check critical files exist
[ -f out/ui-flags/flags/colors.txt ] && echo "colors.txt OK"
[ -f out/ui-flags/localisation/ui-flags_l_english.yml ] && echo "localisation OK"
[ -f out/ui-flags/thumbnail.png ] && echo "thumbnail OK"
[ -d out/ui-flags/flags/backgrounds ] && echo "backgrounds OK"

# 4. Count flags per category
for cat in out/ui-flags/flags/*/; do
    main=$(find "$cat" -maxdepth 1 -name "*.dds" | wc -l)
    map=$(find "$cat/map" -name "*.dds" 2>/dev/null | wc -l)
    small=$(find "$cat/small" -name "*.dds" 2>/dev/null | wc -l)
    echo "$(basename $cat): main=$main map=$map small=$small"
done

# 5. Verify DDS files are valid
# Spot check with: gimp out/ui-flags/flags/human/ui_human_1.dds
```

## Steam Workshop Deployment (Automated)

**Workflow:** `.github/workflows/steam-workshop.yml`

**Trigger:** Git tag push matching `v*.*.*`

**Process:**
```yaml
1. Checkout repository
2. Download release asset (ui-flags_<version>.zip) from GitHub Releases
3. Unzip to release/
4. Upload release/ui-flags/ to Steam Workshop
   - Action: hmlendea/steam-workshop-update
   - AppID: 281990
   - ItemID: 1914541325
5. Changelog includes GitHub release URL
```

**Secrets Required:**
- `STEAM_USERNAME`
- `STEAM_PASSWORD`
- `STEAM_2FASEED`

## Version Management

### Version Sources

| Location | Purpose |
|----------|---------|
| `./build.sh <version>` | Build-time version |
| `MOD_VERSION` in build.sh | Used in descriptors |
| Git tag `v<version>` | Release identifier |
| GitHub Release tag | Distribution identifier |
| Steam Workshop version | Platform version |
| Nexus Mods version | Platform version |

### Consistency Requirements

All version references must match:
- Build argument = Git tag (without `v`) = GitHub Release tag = Distribution filename

**Example:** `./build.sh 1.2.3` → tag `v1.2.3` → release `v1.2.3` → file `ui-flags_1.2.3.zip`

## Rollback Procedure

### If Release Has Issues

1. **GitHub Releases:** Delete release and tag
   ```bash
   git tag -d v1.2.3
   git push origin :refs/tags/v1.2.3
   # Delete release on GitHub web UI
   ```

2. **Steam Workshop:** Use Steam Workshop interface to revert to previous version

3. **Nexus Mods:** Use Nexus Mods interface to hide/remove problematic file

4. **Paradox Mods:** Upload fixed version via web UI

5. **Fix and re-release:** Increment patch version (1.2.3 → 1.2.4)

## Package Integrity Verification

### Checksums

Generate for distribution verification:
```bash
cd out
sha256sum ui-flags_1.0.0.zip > ui-flags_1.0.0.zip.sha256
```

### In-Game Verification

After installing mod:
1. Launch Stellaris
2. Open Mods menu
3. Verify "Universum Infinitum: Flags" appears
4. Enable mod
5. Start new game → Empire customisation
6. Verify all categories present
7. Verify flags render in all three contexts
8. Check error.log for texture errors

## Common Packaging Issues

| Issue | Cause | Fix |
|-------|-------|-----|
| Mod not in launcher | Descriptor path wrong | Verify `path="mod/ui-flags"` in root descriptor |
| Categories missing | Localisation key mismatch | Verify `FLAG_CATEGORY_<dir>` matches directory name |
| Flags missing | DDS format invalid | Rebuild with clean `rm -rf build out` |
| Wrong version shown | Descriptor version stale | Rebuild with correct version argument |
| Thumbnail missing | File not copied | Verify `source/thumbnail.png` exists |
| Backgrounds missing | Copy failed | Verify `source/backgrounds/` has DDS files |
